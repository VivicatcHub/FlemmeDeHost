# Flemme de Host

A simple homepage listing personal projects hosted online, with a favicon and description for each.

## Run locally

No build step or dependencies required. Serve the folder with any static server, for example:

```bash
npx serve .
```

Then open the printed URL in your browser.

## Add a project

Edit [projects.json](projects.json) and add an entry:

```json
{
  "name": "Project Name",
  "url": "https://example.com",
  "desc": "Short description (optional)"
}
```
